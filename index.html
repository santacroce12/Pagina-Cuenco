Proyectos propios

Laboratorio de bicicletas inteligentes

Estamos diseñando un parking inteligente que funciona como hub de servicio: infladores automáticos, herramientas guiadas y un anillo de seguridad IoT para que dejar la bici sea tan simple como estacionar un auto. Vamos documentando cada iteración del diseño.

  • Bahías asistidas con infladores electrónicos y displays que indican la presión ideal según el tipo de bici.
  • Mesas de mantenimiento con soportes, calibradores y guías visuales para ajustar frenos, transmisión y neumáticos in situ.
  • Anillo de seguridad con lockers inteligentes, sensores y videovigilancia analítica para resguardar cada bicicleta.

Publicaremos renders, pruebas de campo y datos de uso a medida que el prototipo evolucione.
